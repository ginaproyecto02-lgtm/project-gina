# Pendientes para el job semanal

Sube aquí los archivos que exporta la extensión (Opciones → **Exportar pendientes para el job de servidor**).
El job junta todos los archivos `.json` de esta carpeta, suma cuántas veces se vio cada marca e investiga primero las más vistas.
Puedes dejar los archivos antiguos: las marcas ya verificadas (o con 3 intentos fallidos) se saltan según `job/estado.json`.
